# Release Notes Version 0.2.0

## Neue Features und Funktionen:

### Aktivitätsdetails

- Aktivität antippen und eine Übersicht der in der FIT-Datei gespeicherten Werte sehen: Strecke, Dauer, Ø- und Max.-Geschwindigkeit sowie Kalorien.
- Herzfrequenz, Trittfrequenz und Leistung jeweils als Durchschnitt und Maximum, außerdem Sportart, Start, Quelle, Höhenmeter und Höhenbereich.
- Nur vorhandene Werte werden angezeigt; bereits gespeicherte Aktivitäten erhalten die neuen Werte automatisch.
